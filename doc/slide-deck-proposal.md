## SLIDE 6 — PAYMENT FLOW: THE TECHNICAL MAGIC

```
HEADER:
Seamless Payment Without Leaving WhatsApp

WHEN USER CLICKS "PAY":

WhatsApp Chat           AstraPay Webview              Result
────────────           ────────────────               ──────

Bot: "Click here    ┌─► App installed?
to pay"             │
                    │   YES → Opens AstraPay
User taps link ────►│   app → enter PIN
                    │          → PAID
                    │
                    │   NO → Stay in webview
                    │         ↓
                    │   Input phone number
                    │         ↓
                    └───────► Enter PIN
                              │
                    ┌─────────┘
                    │   Has account?
                    │   YES → PAID ✅
                    │   NO  → Register here
                    │         ↓
                    └───────► Create account
                              ↓
                            PAID ✅

BACKEND (silent):
AstraPay Push to Payment API → generates payment link
Payment callback → updates order status
Bot sends confirmation → "Order #001 PAID"

WHY THIS MATTERS:
┌─────────────────────────────────────────────────────────┐
│  • Zero install required — webview handles everything    │
│  • No account linking — Push to Payment uses HP + PIN   │
│  • Fallback is seamless — register in-web if needed     │
│  • Fits AstraPay SNAP BI standards                      │
└─────────────────────────────────────────────────────────┘
```
